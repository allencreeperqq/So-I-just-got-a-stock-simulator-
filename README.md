爬蟲-運算

---
大綱:

1. USE CASE 
   a.客群:大學生/股票投資新手
   b.使用:爬蟲抓實際股票走勢 模擬股票交易
   c.功能:教學提示/助手/名詞解釋/風險分析

2. 大致系統流程
   1. 爬蟲建置並存取股市
   2. 輸入使用者資金及選擇欲投資之股市
   3. 儲存購買資訊 持續更新股市 並計算獲利情況及風險
   4. 輸出獲利情況及風險

---
網頁流程
1. 先顯示登入頁面以及網頁logo
2. 按下登入後顯示首頁:顯示目前資產(預設100萬) 並且生成一個資產圖表(折線圖)在中間，右手邊放上已加入最愛的股票資訊(預設台股0050、NVIDIA、APPLE等)，左手邊最上面是回到首頁，依序往下有數個按鈕，分別是市場、交易、資產。
3. 點入市場，出現目前的股票市場圖(預設APPLE)，搜尋框、以及資訊欄，當對搜尋欄搜索股票代號，可以顯示今天的股市。
4. 點入交易，可以輸入你想要買的股票代號，並且模擬購買。在這個頁面也要有股票市場的資訊。
5. 買入之後，在首頁的資產可以看到目前的持倉。

---
執行方式
1. 安裝套件：`pip install yfinance`
2. 啟動後端：`python financial.py`
3. 打開 [index.html](index.html)（前端會呼叫 `http://localhost:8000/api`）

### [v1.5.0] - 2026-06-12
Added
- **Dark Mode (夜間模式)**: 導入 CSS 變數系統，支援全域明暗主題無縫切換，提升長時間觀看的舒適度。
- **金融學院 (Knowledge Base) 獨立頁面**: 將教學助手獨立為全新分頁，內含 K 線圖原理、當沖概念與加密貨幣等專屬圖文解說。
- **GitHub 專案連結**: 於側邊欄底部新增可直接跳轉至原始碼庫的按鈕。

Fixed
- 修復切換 K 線圖與折線圖時，若資料筆數極少 (1-2 筆) 會導致 Canvas 渲染出巨大十字架或漸層變形的數學溢位 Bug。

### [v1.4.0] - 2026-06-10
Added
- **K 線圖 (Candlestick Chart) 支援**: 前端實作擬真 OHLC 演算法，支援在市場與交易介面即時切換折線圖與 K 線圖。
- **加密貨幣支援**: 整合 Yahoo Finance API，現在可輸入如 `BTC-USD`、`ETH-USD` 進行虛擬貨幣模擬交易。

### [v1.3.0] - 2026-06-08
Added
- **專業級圖表視覺**: 走勢圖新增背景網格 (Grid)、半透明漸層填色 (Gradient Fill)，並加入紅綠趨勢自動變色邏輯。
- **Tooltip 名詞解釋系統**: 於重要金融名詞加上虛線底線，游標懸浮即可彈出教學視窗。
- **股市小百科區塊**: 於最愛清單下方新增常駐型金融術語解釋區塊。

### [v1.2.0] - 2026-06-07
 Added
- **動態資產軌跡**: 首頁資產圖表不再使用預設正弦波，改為真實記錄每一次交易與價格跳動的平滑折線圖。
- **即時未實現損益**: 在模擬當沖過程中，損益與總資產數字會隨著每一個 Tick 即時更新並變色。
- **加入最愛功能**: 支援在市場搜尋後，一鍵將標的加入右側最愛清單。
- **點擊跳轉機制**: 點擊右側最愛清單的標的，將自動跳轉至市場分頁並渲染該標的走勢。

Fixed
- 修復暫停按鈕帶有導覽列 (nav-btn) class 導致點擊時畫面全數隱藏的 Bug。

### [v1.1.0] - 2026-06-06

- **模擬控制功能**: 新增「開始模擬」、「暫停/繼續模擬」按鈕。
- **交易防呆提示彈窗 (Modal)**: 在啟動模擬前加入彈出式確認視窗，宣導當沖風險與機制。
- **即時庫存顯示**: 於市場資訊區塊新增持有股數的動態顯示。
